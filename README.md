🇷🇺 Описание
Программа для защиты компьютера с помощью распознавания лица. Если система не видит владельца перед камерой — компьютер автоматически блокируется.
🇬🇧 Description
A desktop security tool that uses face detection to protect your computer. If the system does not detect the authorized face, the computer will automatically lock.

⚙️ Как работает / How It Works
🇷🇺
Программа использует камеру компьютера для анализа изображения в реальном времени. Если лицо пользователя не обнаружено в течение определённого времени — система выполняет блокировку Windows.
🇬🇧
The program uses your computer's camera to analyze the video feed in real time. If the user's face is not detected for a certain period of time, the system locks Windows automatically.

🔒 Безопасность / Security
🇷🇺

Программа не отправляет данные на серверы
Все вычисления выполняются локально
Видео с камеры не сохраняется
Личные данные не собираются

🇬🇧

No data is sent to external servers
All processing happens locally
Camera footage is not stored
No personal data is collected
