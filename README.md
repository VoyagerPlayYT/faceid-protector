# FaceID Protector

Программа для защиты компьютера с помощью распознавания лица.
Если система не видит владельца перед камерой — компьютер автоматически блокируется.

A desktop security tool that uses face detection to protect your computer.
If the system does not detect the authorized face, the computer will automatically lock.

---

**RU**

* 🔐 Блокировка компьютера при отсутствии лица
* 🎥 Использование веб-камеры для распознавания
* ⚡ Быстрая работа в реальном времени
* 🧠 Использование OpenCV
* 🖥 Поддержка Windows
* 🚀 Автозапуск при запуске системы
* 🎯 Простая установка

**EN**

* 🔐 Locks the computer when the authorized face is not detected
* 🎥 Uses the webcam for face recognition
* ⚡ Real-time processing
* 🧠 Powered by OpenCV
* 🖥 Windows support
* 🚀 Optional auto-start with Windows
* 🎯 Simple installation

# ⚙️ Как работает / How It Works

**RU**

Программа использует камеру компьютера для анализа изображения в реальном времени.
Если лицо пользователя не обнаружено в течение определённого времени — система выполняет блокировку Windows.

**EN**

The program uses your computer's camera to analyze the video feed in real time.
If the user's face is not detected for a certain period of time, the system locks Windows automatically.

**RU**
